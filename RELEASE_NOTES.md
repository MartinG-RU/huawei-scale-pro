# Huawei Scale 3 Pro 1.5.0

- Локальное подключение весов по Bluetooth к Home Assistant.
- Общий набор сенсоров, профили пользователей и выбор по весу.
- Отдельные гостевые данные и кнопка «Забыть гостя».
- Русские названия показателей и настройки.

Установка вручную: распакуйте `huawei_scale_pro.zip` в `/config/custom_components/` и перезапустите Home Assistant. Также можно добавить этот репозиторий в HACS как пользовательскую интеграцию.

Показатели состава тела являются приблизительными оценками. Другие модели и прошивки, кроме проверенной Scale 3 Pro, могут работать иначе.
